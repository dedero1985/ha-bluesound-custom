# Bluesound Custom (Library, Radios & Streaming)

Custom Home Assistant integration for Bluesound / BluOS devices with rich
**media browsing**:

- Local library (artists / albums / tracks / folders / genres)
- Internet radio (TuneIn, iHeartRadio, ...)
- Favourite presets (the buttons on the BluOS app)
- Streaming services (Spotify, Tidal, Qobuz, Deezer, Amazon Music, ...)
- Saved playlists

Plus the usual transport controls (play / pause / stop / next / previous / seek),
volume, mute, shuffle, repeat, and Zeroconf auto-discovery.

Designed to coexist with the official `bluesound` integration — this one uses
the domain `bluesound_custom`.

See the [README](https://github.com/dedero1985/ha-bluesound-custom)
for setup details.
